Using PyQSense
==============

Installation
------------
PyQSense is provided as a python package.
Here is a quick recipe for installation

.. code-block:: shell

    $ git clone https://github.com/WPI-Quantum-Sensing-Lab/PyQSense.git
    $ cd PyQSense
    $ python -m venv .venv
    $ source .venv/bin/activate
    $ pip install .

PyQSense can be installed in other ways too.
If it is available on `PyPI`_, then a simple ``pip install`` will work without the need to clone the git repository.
Any package manager (e.g. ``uv``) that can handle python projects using ``pyproject.toml`` files should be able to install PyQSense too.

.. _PyPI: https://pypi.org

PyQSense comes with some optional dependency groups that one may choose to install in addition to the base package using ``pip``'s ``--group`` flag.
They are mostly for development; at this time, no dependency group enables additional functionality in the experiment.
Consult the ``pyproject.toml`` for the available groups.

Configuration
-------------
PyQSense reads a YAML configuration file on startup.
It must be called ``devices.yaml`` and you must set the environment variable :envvar:`PYQSENSE_CONFIG_PATH` to the directory containing the file.
The available options are browseable `here`_ and further documented in :doc:`options`.

.. _here: /_static/devices.schema.html

Running Experiments Using PyQSense
----------------------------------

PyQSense is a code library; launching and managing experiments is a task delegated to the user.
One way to do this is by using python scripts that configure site-specific settings and experiment-specific parameters, then selectively launching them based on the desired configuration.
The launcher should subclass :py:class:`PyQSense.gui.Experiment_Process` and use :py:meth:`PyQSense.gui.Experiment_Process.set_exp` to load one of the experiments in :py:mod:`PyQSense.experiments`.
For manual calibration of the experimental apparatus, instantiating :py:class:`PyQSense.gui.Viewer_Window` may be of interest.
