PyQSense Device Configuration

Type: object

Specify settings for physical devices used in PyQSense

root ttl
Type: object

TTL logic card config

root ttl type
Type: string

Unqualified name of class to load from ttl_control module. For example, Pulse_Blaster.

root ttl channels
Type: object

TTL channel configurations per channel

root ttl channels channel_number
Type: number

Output line number. The meaning of this setting is implementation-dependent. If using a PulseBlaster, this is the output pin number according to the numbering in their C API.

root ttl channels start_offset
Type: number

Time (in ns) to add to every pulse start time.

root ttl channels width_offset
Type: number

Duration (in ns) to add to every pulse.

root cam
Type: object

Camera configuration

root cam type
Type: string

Unqualified name of class to load from cam_control module. For example, Basler_Camera.

root cam frame_trigger
Type: string

The hardware trigger source for a single image acquisition. For example, "Line1".

root cam burst_trigger
Type: string

The hardware trigger source for a burst of images.

root mw
Type: object

Microwave configuration

root mw address
Type: string

The VISA resource name of the microwave generator. For example, "ASRL3::INSTR".

root mw model_name
Type: string

The model name given by the *IDN? SCPI command. For example, "Standford Research Systems,SG380,s/n1234,ver1.104".

root mw baudrate
Type: number

The symbol rate (in baud) of the instrument. This does not set the symbol rate, but indicates what symbol rate the instrument expects.

root additionalProperties
Type: object

Auxiliary device configs. The names must correspond to those hardcoded in PyQSense, just like the microwave configuration object must be named "mw".

root additionalProperties type
Type: string

Unqualified name of class to load from aux_control module.

root additionalProperties additionalProperties
Type: object

Keyword arguments to pass to __init__ method of the device class.
